Syllabus ID: 13166
Syllabus Name: Operating System_Hệ điều hành
Course Name English: Operating System
Subject Code: OSG202
Learning-Teaching Method: Social Constructivism,In-class lecture,Inquiry-based Teaching
NoCredit: 3
Degree Level: Bachelor
Time Allocation: Study hour (150h) = 45h contact hours + 1h final exam + 104h self-study'
Pre-Requisite:
Description: At the end of this course, students will be able to perceive:
1) Background knowledge: (ABET e)
-The role of operating system,
- important OS concepts,
- the mechanism of operating system, and
- main problems of Operating system.
2) Practice skills: (ABET k)
- Using basic shell command in Linux system fluently.
- Fundamental of shell, C language on Linux.
- Main problems of Operating system through some simulative exercises.
3) Information searching, reading and selection skills (ABET i)
4) Working in group, documenting and presenation skills (ABET g)
StudentTasks: - Students must attend at least 80% of contact slots in order to be accepted to the final examination.
- Student is responsible to do all exercises given by instructor in class or at home and submit on time
- Use laptop in class only for learning purpose
- Promptly access to the FU LMS https://flm.fpt.edu.vn/ for up-to-date course information
Tools: - Internet
- Linux operating system server and/ or desktop
- MARIE simulator
- AI tools (ChatGPT/Copilot/Gamma…) and other simulation software if deemed appropriate.
