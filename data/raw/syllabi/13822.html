Syllabus Details

Syllabus ID: 13822
Syllabus Name: Mobile Programming_Lập trình di động
Course Name English: Mobile Programming
Subject Code: PRM393
Learning-Teaching Method: Project based learning, In-class lecture, Inquiry-based Teaching
NoCredit: 3
Degree Level: Bachelor
Time Allocation: Study hour (150h) = 45h contact hours + 1h final exam + 104h self-study
Pre-Requisite: PRO192
Description: 1. Understand the fundamental concepts of mobile programming with Flutter and Dart.
2. Experience using popular widgets and plugins to build cross-platform user interfaces.
3. Knowledge of state management, form handling, and navigation between screens in mobile applications.
4. Learn and apply asynchronous programming techniques with Future and async/await.
5. Ability to integrate RESTful APIs to exchange data between mobile applications and servers, as well as store data locally using SharedPreferences and SQLite.
6. Proficient in using Dart libraries and command-line tools to optimize the application development process.
7. Knowledge of implementing mobile notification systems, including local and push notifications.
StudentTasks: - Students must attend more than 80% of contact sessions in order to be accepted to the final examination.
- Student is responsible to do all assigned exercises given by instructor in class or at home and submit on time
- Use laptop in class only for learning purpose
- Promptly access to the FU LMS at http://lms.fpt.edu.vn for up-to-date course information
Tools: - Android Studio + Flutter SDK + Dart SDK (Latest Version)
- Virtual device attached android studio (or other virtual device), android mobile (only for learning, not for exam - optional)
- Laptop: 16GB RAM, 25GB free space before installing studio
Note:
- Install all neccessary tools before the first slot of the course
