Syllabus Details

Syllabus ID: 850
Syllabus Name: COMPUTER ORGANIZATION AND ARCHITECTURE
Course Name English:
Subject Code: CEA201b
Learning-Teaching Method:
NoCredit: 3
Degree Level: Bachelor
Time Allocation: 45 hours (3 credits):
- 25 online sessions
- 4 offline sessions (90 minutes/session)
- 1 final exam
Pre-Requisite:
Description: After taking this course, the students should all be able to:
G1. Know the concepts of information, coding, error correction, and multiplexing. Understand how to represent numbers in binary, hexadecimal, numbers with offset 2 and basic operations.
G2. Knowing knowledge, basic logic operations. Understand the laws of Boolean algebra so that it can be used to reduce expressions and design of integrated logic circuits
G3. Know the basic concepts in computer organization and architecture such as stored programs, script architectures (properties, functions, formats), storage and memory access, representation operands. Know how to use simulation software for program testing and debugging.
G4. Understand concepts of assemblies to be able to write simple programs. Distinguish the difference between linguistic and high-level languages.
G5. Knowing the concepts and knowledge in the memory system is decentralized: SRAM, DRAM, Flash, hard drive.
Understand the basic concepts of cache like:
+ locality principle (locality of reference) when accessing memory
+ How to access the cache
+ size 1 block of data in the cache
+cache hit, cache miss
+conflict miss
StudentTasks: - Students should self-study all lessons on LMS before the offline class
- Take part in at least 4/4 offline sessions
- Submit projects in order to unlock the next lessons
