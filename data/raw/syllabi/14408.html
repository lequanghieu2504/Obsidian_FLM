Syllabus ID: 14408
Syllabus Name: Digital Circuit Design_Thiết kế vi mạch số
Course Name English: Digital Circuit Design
Subject Code: DCD301
Learning-Teaching Method: Inquiry-Based Learning, In-class lecture, Active Learning
NoCredit: 3
Degree Level: Bachelor
Time Allocation: 45h (60 sessions) contact hours + 1h final exam + 104h self-study
Pre-Requisite: ECI101
Description: This course provides students with a solid and comprehensive foundation in digital circuit design. It begins with essential concepts such as number systems, logic gates, Boolean algebra, and logic function simplification. Students then advance to designing and implementing combinational and sequential logic circuits, including multiplexers, arithmetic circuits, flip-flops, shift registers, counters, and memory elements.
The course also introduces hardware description languages (VHDL/Verilog), FPGA-based implementation, and fundamental principles of digital signal and data processing. Through these topics, students learn how hardware is described at the Register-Transfer Level (RTL) and how it is verified using testbenches and simulation.
In addition, the course provides an overview of the Digital IC Design Flow, including:
- Specification and Functional Requirements
- RTL Design using HDL
- Functional Verification and Testbench Development
- Logic Synthesis to Gate-Level Netlist
- Timing Analysis and Optimization
- Implementation on FPGA or placement & routing (for ASIC)
- Post-synthesis simulation and sign-off checks
The module emphasizes not only technical competence but also professional ethics, social responsibility, and the development of creativity and problem-solving skills. Students apply theoretical knowledge through laboratory exercises, hands-on projects, and real-world design practices.

- Use laptop in class only for learning purpose
