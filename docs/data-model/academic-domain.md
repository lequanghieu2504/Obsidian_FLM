# Academic domain

The canonical model will represent programs, curricula, semesters, courses, syllabi, topics, learning outcomes, assessments, materials, and prerequisites independently of FLM markup and storage technology.

Entities require stable identifiers such as `course:PRM393`; display names are not identity. Raw FLM representations remain in `flm_core/raw` and are mapped into the canonical model with provenance and schema-version awareness.
