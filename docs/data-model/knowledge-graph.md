# Academic knowledge graph

The graph is storage-agnostic and centered on nodes, edges, relation types, provenance, evidence, confidence, and timestamps. Official relations and inferred relations are separate categories so an inference can never be presented as an FLM fact.

Official examples include `BELONGS_TO_PROGRAM`, `HAS_SYLLABUS`, and `TEACHES_TOPIC`. Inferred examples include `RELATED_TO`, `RECOMMENDED_BEFORE`, and `SIMILAR_TO`.
